Screenshots used by the built-in User Manual (index.php?p=manual).

Each file is named after the route it shows, so assets/manual/employees.png is the
screenshot of index.php?p=employees. app/manual.php picks the file up automatically;
an article can point at another file with the 'shot' key in app/manual_content.php.

To refresh a screenshot: open the page, take a 1440px-wide screenshot of the whole
window and save it over the file of the same name. Nothing else needs to change.

The screenshots were taken against the sample company in database/ihris_mysql55_demo.sql,
so the names and figures in them are demo data, not live records.
